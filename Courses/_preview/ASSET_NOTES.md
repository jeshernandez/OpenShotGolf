# Preview CC0 Turf Assets

These preview textures are for visual review before they are promoted into shared course assets.

Source: ambientCG

License: CC0

Assets used:
- Grass005, packed as the green preview texture.
- Grass008, packed as the fairway preview texture.
- Grass007, packed as the rough preview texture.

Runtime files are exported at 1024 x 1024 so every Terrain3D albedo texture and normal texture in this preview uses the same size.
